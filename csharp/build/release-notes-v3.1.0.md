# iOpenPod 管理器 v3.1.0

本次新增三个差异化功能，全部接入同步流程与设置界面。

> ⚠️ **实验性版本**：标签写回默认关闭。MP3 / FLAC 路径已实测；
> MP4 / WAV / Ogg / AIFF 的写入路径尚未验证，请勿在重要文件上开启。
> Rockbox 引导程序安装会改写 iPod 固件分区，操作前请先备份设备。

## 新增

### 1. 元数据写回源文件
同步完成后，把设备上最终生效的元数据反向写回电脑上的源文件。

- 覆盖 ID3v2.3/2.4（MP3、含 id3 块的 WAV/AIFF）、MP4 ilst、FLAC
  Vorbis Comment、Ogg Vorbis/Opus、WAV LIST/INFO、AIFF 文本块
- 「能表达多少字段就写多少」，写不了的字段在结果里列出，不会整体失败
- 原子写入（临时文件 + 替换），可选 `.iopenpod.bak` 备份
- 幂等：无变化时文件字节零改动
- 保留未修改的帧、未知原子、未知注释键、封面区以外的块
- 设置中可开关，**默认关闭**

### 2. 视频入库与自动转码
- 调用外部 FFmpeg 探测媒体流（编码、分辨率、码率、帧率）
- 按设备档案推导转码参数：H.264 档次、最大分辨率、帧率、码率
- 同步前自动转换，输出为设备可直接播放的 M4V/MP4
- 带进度回调（解析 ffmpeg `-progress` 输出）
- 未安装 FFmpeg 时降级为跳过并给出中文提示，不影响其它项目
- 同步计划中会标注哪些项目需要转码

### 3. 内置 Rockbox 安装
- 支持机型：iPod 1/2/3/4/photo/color/5/5.5 代、classic 6/6.5/7、
  mini 1/2、nano 1/2/3（后两者标记实验性）
- 四种模式：仅系统文件（可逆）、完整安装、仅引导程序、卸载
- 镜像站可配置；release / daily 通道；可指定版本号
- 安装参数：备份固件分区、备份 Apple 固件、保留双启动、
  备份已有安装、自定义 ipodpatcher 参数、自备文件路径
- ipodpatcher 以管理员权限调用；iPod classic 走 mks5lboot（DFU 模式）
- 防 Zip Slip、SHA256SUMS 校验、断点续传下载
- 同步时可选自动安装系统文件（仅在设备上还没有 Rockbox 时）

### 界面
- 新增 Rockbox 页面（设备状态、安装参数、执行进度、步骤日志）
- 设置页新增「媒体工具与转码」「标签写回源文件」「Rockbox」分组
- 同步页显示媒体工具状态与设备视频能力

## 已知限制

- **标签写回**：MP4 / WAV / Ogg / AIFF 写入路径未实测；
  WAV LIST/INFO 存在读取器游标问题；ID3v2.2 不处理
- **视频转码**：需用户自行安装 FFmpeg（程序只检测，不自动下载）
- **Rockbox**：iPod nano 2 代与 classic 的引导程序安装需用户自备工具；
  引导程序是否写入只能通过 `ipodpatcher --list` 文本启发式判断

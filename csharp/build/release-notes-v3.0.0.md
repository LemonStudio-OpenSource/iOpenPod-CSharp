# iOpenPod 管理器 v3.0.0 —— C# / WinUI 3 中文重制版

iOpenPod 的**完全 C# 重写版**：界面、日志与所有用户可见内容均为中文，使用 .NET 10 + WinUI 3 构建，发行包自带 .NET 运行时。

> 基于 [TheRealSavi/iOpenPod](https://github.com/TheRealSavi/iOpenPod) 重制，授权 GPL-3.0-or-later。

## 下载与安装

1. 下载 `iOpenPod-v3.0.0-win-x64.zip` 并**完整解压**（不要只复制 exe，整个目录都要保留）。
2. 双击 **`首次运行-安装运行时.cmd`** —— 安装一次微软官方的 Windows App Runtime 1.8 组件（不需要管理员权限，已装过会自动跳过）。
3. 双击 **`iOpenPod.exe`** 启动。

> **为什么必须先装运行时**：WinUI 3 应用除了自带 .NET 之外，还需要操作系统级的 Windows App Runtime 才能初始化图形合成器。缺少它时窗口会出现、标题栏也正常，但客户区一片空白且不报任何错。发行包里的 `Runtime\` 目录已附带微软官方的四个 MSIX 组件，脚本失败时可以手动依次双击安装。

## 功能

* **浏览**：歌曲 / 专辑 / 艺术家 / 流派四种视图，封面缩略图、搜索、多字段排序、专辑详情页。
* **播放**：底部播放条（上一首 / 播放暂停 / 下一首 / 进度拖动 / 音量）、播放队列与歌词面板。
* **编辑**：曲目元数据编辑器（标题、艺术家、专辑、流派、作曲者、备注、分组、歌词、音轨号、碟号、年份、BPM、评分、媒体类型、合辑标记等），支持多选批量应用；播放列表新建 / 重命名 / 删除 / 增删曲目；设备重命名。
* **同步**：递归扫描多个宿主媒体文件夹，自动解析 ID3v1 / ID3v2.2-2.4、MP4、FLAC、Vorbis、WAV、AIFF、ASF 标签与内嵌封面；生成新增 / 更新 / 移除计划（移除项默认不勾选）；媒体文件、封面分片与数据库在同一个可恢复事务中提交。
* **备份快照**：完整备份 `iPod_Control` 与 `Photos`，附带 JSON 清单与 SHA-256；还原前强制再创建一次安全快照。
* **设备**：自动发现并识别已挂载的 iPod（内置 151 个型号 / 218 个序列号后缀 / 35 组 USB 标识），原生安全弹出，明确的只读与不支持提示。
* **诊断**：全中文日志，界面可实时筛选查看，也可复制或打开日志目录。

## 技术要点

* **无损数据库**：iTunesDB / ArtworkDB / PhotosDB 以保留原始字节的数据块树表示，写入时只重算长度与子块计数 —— 解析后写回可**逐字节重现**原始文件。
* **签名**：HASH58、HASH72（AES-128-CBC，IV 可从设备恢复）、HASHAB（EDON-R′ 256 + Apple 密码表，移植自 dstaley/hashab 的公有领域 C 实现，通过全部 100 组官方向量）。
* **可恢复写入事务**：暂存 → SHA-256 校验 → 写日志 → 发布写入 → 执行删除 → 校验 → 清理，每个被替换或删除的原文件先进入备份区。

## 校验

源码自带离线校验程序：

```shell
dotnet run --project csharp/tests/iOpenPod.Verification -c Release
```

可验证：真实捕获的数据库逐字节往返、HASH58 官方向量、HASHAB 全部 100 组官方向量、设备目录与 SysInfo 识别、编辑后逐字节复原、播放列表增删往返 —— 当前 **26 项全部通过**。

## 已知限制

* iPod nano 5 / 6 / 7 代当前为只读（可浏览、播放、备份）。
* 同步默认保持原格式，不做音频转码。
* 尚未实现：智能播放列表规则编辑、照片库管理、播客订阅、Last.fm / ListenBrainz 记录、macOS / Linux 版本、应用内自动更新。
